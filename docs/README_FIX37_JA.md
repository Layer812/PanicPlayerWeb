# FIX37 — GUI整理と音声付き連続再生

基準: FIX36（映像優先順位、16MHz、実時間制御、ADPCM、パレット補正）を維持。CPU/Cバス/WASMの描画エンジンは未変更です。

## 操作

- **PLAY / STOP**: 単一トグルボタン。PLAYはWebAudioをユーザークリックの中で有効化して再生。STOPはCPUと音声を停止。
- **PREV / NEXT**: 押した時点でWebAudioを有効化し、実行中なら停止してから前／次のPANを先頭から再生。末尾・先頭は循環。
- **REPEAT**: 現在のPANを終了したら同じPANを繰り返す。
- **FOLDER AUTO**: インポートしたフォルダ／一覧をパスの自然順に再生。最終PANが終わったら先頭に戻る。
- REPEATとFOLDER AUTOは排他的。どちらも未選択なら再生終了後に停止。
- **FULL**: 画面全体の表示。

ファイル選択とドラッグ＆ドロップを維持。診断を画面・ライブラリの下に移し初期状態では閉じ、異常停止時に自動展開します。診断コピーは従来どおり利用できます。パレット・V-DISP・ADPCMの詳細行は診断内に移動しました。

著作権・謝辞は画面最下部および `THIRD_PARTY_NOTICES.md` に記載。リポジトリのトップが空の場合でもリンクを表示します。
